# fast-stage-code-

## PACPACMAN（ブラウザ版）

不具合対策のため、ゲームコードを最初から全面的に書き直しました。  
起動すると、オープニング画面が**下からスクロールイン**して表示されます。

## すぐ遊ぶ手順
1. `index.html` をブラウザで開く
2. オープニング表示後に `Enter` を押してスタート
3. `← ↑ → ↓` で移動
4. ゲームオーバー後は `Enter` でオープニングへ戻る

## 今回の修正ポイント
- 迷路中央の巣ドアをゴースト専用で通過可能にし、**中心から出られない問題を修正**
- ゴーストを時間差で外へ出す処理を追加
- 迷路パターンを **10パターン** 用意し、ラウンドごとに切り替え

## 主な仕様
- 青い迷路、ドット、パワーエサ
- 4体のモンスター
- パワーエサ中はモンスターが弱体化
- ドットを全部食べると次ラウンド
- 画面上部にスコア/ハイスコア/ラウンド/残機を表示

## ファイル
- `index.html` : 画面
- `style.css` : 見た目
- `game.js` : ゲーム本体ロジック（全面再実装）
