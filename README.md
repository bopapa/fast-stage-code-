# fast-stage-code-

## クラシック迷路ゲーム（ブラウザ版）

添付の参考画像に寄せて、
- 黒背景 + 青いネオン風の壁
- 黄色キャラクターと4色モンスター
- 上部スコア表示（1UP / HI）
を意識したブラウザゲームです。

## 遊び方
1. `index.html` をブラウザで開く
2. `← ↑ → ↓` で移動
3. パワーエサを取ると、モンスターが青くなって反撃可能
4. ドットを全部取るとラウンドクリア
5. やられると残機が減り、0でゲームオーバー（`Enter` で再開）

## 実装済みの要素
- 4体のモンスター（役割差あり）
- 巣からの時間差出撃
- 縄張りモード / 追跡モードの切り替え
- 切り替え時の進行方向反転
- ワープトンネル（左右端）
- モンスターのみ一方通行制約
- イジケ状態（青化 + 終了前点滅）
- 撃退後は目玉で巣へ帰還
- フルーツ2回出現（約10秒で消える）
- コーヒーブレイク（2,5,9,13,17クリア後）

## ファイル
- `index.html` : 画面
- `style.css` : デザイン
- `game.js` : ゲーム本体
