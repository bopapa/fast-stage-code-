# fast-stage-code-

## Codexの可能性デモ（非エンジニア向け）

このリポジトリは、**「Codexでどんなことができるか」**を体験するためのミニデモです。

### できること（例）
- アイデアから、たたき台の文章を作る
- 作業の手順を、わかりやすいチェックリストにする
- 既存の文章を、やさしい日本語に言いかえる
- 修正内容を履歴として残し、チームで共有しやすくする

### 1分デモの流れ
1. やりたいことを1文で伝える
2. Codexが「最初の案」を作る
3. 直したい点を伝える
4. Codexが改善し、結果をまとめる

### 伝え方のコツ
- 長文より、短く区切って伝える
- 「誰向けか」を最初に書く（例：初心者向け）
- 「どこまでほしいか」を決める（例：3案だけ）

### サンプル指示（そのまま使えます）
> プログラミング未経験の人向けに、
> 「AIで日報を時短する方法」を
> 100文字で3パターン作ってください。
