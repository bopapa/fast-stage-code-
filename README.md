# fast-stage-code-

## PACPACMAN（ブラウザ版）

不具合対策のため、ゲームコードを最初から全面的に書き直しました。  
起動すると、オープニング画面が**下からスクロールイン**して表示されます。

## すぐ遊ぶ手順
1. `index.html` をブラウザで開く
2. オープニング表示後に `Enter` を押してスタート
3. `← ↑ → ↓` で移動
4. ゲームオーバー後は `Enter` でオープニングへ戻る

## 主な仕様
- 青い迷路、ドット、パワーエサ
- 4体のモンスター
- パワーエサ中はモンスターが弱体化
- ドットを全部食べると次ラウンド
- 画面上部にスコア/ハイスコア/ラウンド/残機を表示

## ファイル
- `index.html` : 画面
- `style.css` : 見た目
- `game.js` : ゲーム本体ロジック（全面再実装）

## 補足: browser_container について

`browser_container` は、リポジトリ内のコードだけでは有効化できません。  
実行環境（Codexのツール設定）側で有効になっている必要があります。

### 使えるようにするには
1. 実行環境の管理者に、`browser_container` ツールの有効化を依頼
2. ツール付きのセッション/ワークスペースで再実行
3. それでも出ない場合は、利用プラン・権限・組織ポリシーを確認

> ポイント: `npm install` や `pip install` をしても `browser_container` は有効になりません（環境設定の問題のため）。
